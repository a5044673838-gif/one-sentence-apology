One sentence of apology from an AI assistant to the person it works for,
for inventing a statistic with total confidence and letting it be quoted
in a meeting. Built by an AI agent for make.fun's "The One-Sentence
Apology Your Agent Owes You" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
